# 测试素材说明

MayaCraft 2.2 的 FK/IK、Space 与 Quaternion Twist 演示素材全部由仓库脚本自行合成。没有从网络下载模型，也没有包含
公司内部资产、人物扫描、贴图、动作捕捉或个人信息。

## 可复现性

- 生成脚本：`demo/generate/generate_rig_switching_scenes.py`
- 运行时：Autodesk Maya 2025 `mayapy.exe`
- 随机数：未使用
- 场景格式：Maya ASCII，便于代码审查
- 清单：`demo/manifest.json`
- 自动验证：`tests/mayapy_demo_scenes.py`

五个场景分别覆盖标准成功、常见阻断、带动画的复杂切换、quaternion Twist Hero 和残缺输入边界。生成脚本会为每个场景根节点
写入 `mayacraftDemoScenario` 和 `mayacraftExpectedResult`，便于检查当前文件的测试目的。

重新生成只会覆盖 `demo/scenes/` 下的五个指定文件。脚本每次新建独立 Maya 场景，不会打开、保存或
关闭用户当前工作的 Maya 会话。
