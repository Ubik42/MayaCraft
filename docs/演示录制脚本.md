# MayaCraft 2.1 演示录制脚本

建议录制 4–6 分钟，使用 1120×760 左右的 MayaCraft 停靠尺寸。录制前关闭无关 Outliner、插件弹窗和
开发日志，使用仓库中的演示场景，避免依赖个人项目路径。

## 第一段：角色语义与绑定图（约 50 秒）

1. 打开 `mayacraft_match_success.ma`，停在第 12 帧。
2. 从 Maya 中选择左手骨骼，打开 MayaCraft。
3. 简短展示角色工作区与 Maya 选择双向同步。
4. 进入“绑”，说明 7 个模块、73 个对象、34 条真实行为和 107 项读回结果。
5. 点击左右手臂、腿部，展示画布和 Inspector 同步聚焦。

推荐讲解：“这不是根据节点名字猜绑定成功，而是会反查真实 DG 连接；拔掉矩阵线后会定位到具体行为。”

## 第二段：FK → IK 无跳变（约 90 秒）

1. 展示第 12 帧弯曲 FK 手臂。
2. 点击“预览 FK → IK”，停留两秒展示青色零写入计划。
3. 强调预览阶段 Maya 场景没有变化。
4. 点击应用，展示仪表从 FK 100% 移动到 IK 100%。
5. 放大状态：“最大位置误差 0.000000 / 已设关键帧 / 可整块撤销”。
6. 在 Channel Box 或 Graph Editor 展示 `ikFk`、Pole、Twist 与补偿键。
7. 拖动 IK 控制器，证明已经真实进入 IK。

推荐讲解：“RP IK 会产生关节 Roll 差异，我没有把误差阈值调大，而是为三段输出加入可关键帧的旋转补偿，并在写后逐关节读回验证。”

## 第三段：Space Switch（约 70 秒）

1. 打开 `mayacraft_space_switch.ma`，停在第 12 帧。
2. 选择“胸腔空间”，生成预览。
3. 指出第 11 帧旧空间保护键和第 12 帧补偿键。
4. 应用后前后切帧，证明切换瞬间手腕不跳；继续播放，证明后续跟随胸腔。
5. 点击撤销，展示绿色恢复回执。

## 第四段：可信失败（约 45 秒）

1. 打开 `mayacraft_match_locked.ma`。
2. 预览 FK→IK，展示锁定 `translateX` 的红色阻断状态和禁用应用按钮。
3. 打开 `mayacraft_skeleton_blocked.ma`，扫描残缺骨架。
4. 展示缺失语义说明，强调不会在原点生成一堆“看起来成功”的空控制器。

## 收尾（约 30 秒）

展示 README 的真实截图和测试证据，说明当前只支持 Maya 2025；Twist/Bendy、Face PSD/RBF 等尚未完成
的能力被明确放在后续，而不是隐藏在不可用按钮后面。
