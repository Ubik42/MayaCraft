# MayaCraft 2.3 使用教程

本教程面向第一次接触仓库的人，目标是在 Maya 2025 中从演示场景完成一次真实 FK→IK 匹配、
一次 Space Switch 和一次完整撤销。所有场景修改都发生在独立测试文件中。

## 1. 环境与启动

支持环境：Windows、Autodesk Maya 2025、Maya 自带 Python 3.11、PySide6 6.5.3。

把 `MayaCraft` 仓库的父目录加入 Maya 的 Python 搜索路径。例如仓库位于
`D:\3D\_tools\MayaCraft`。推荐先在仓库根目录执行：

```powershell
.\install\install_maya2025.ps1 -Preview
.\install\install_maya2025.ps1
```

第一行只显示即将写入的 Maya Module 配置，第二行才在当前用户的
`Documents\maya\2025\modules` 写入并读回验证 `MayaCraft.mod`。如需手动安装，则把
`D:\3D\_tools` 加入 `PYTHONPATH`。随后在 Maya Script Editor 的
Python 页签运行：

```python
import MayaCraft.launch as launch
launch.run()
```

界面会以 `MayaCraftWorkspaceControl` 停靠在 Maya 中。重复执行会清理旧窗口和 callback，再重新打开。

## 2. FK → IK 无跳变匹配

1. 打开 `demo/scenes/mayacraft_match_success.ma`。
2. 时间线停在第 12 帧。左臂已经有一组明显的 FK 弯曲姿态。
3. 打开 MayaCraft，点击左侧“绑”。绑定图应显示 137 个对象、50 条物理行为、187 项均为“保留”。
4. 点击画布中的“左臂”，右侧出现“动画匹配舱”。
5. 点击“预览 FK → IK”。此时 Maya 场景不应发生变化；状态会说明要匹配末端和 Pole，并在当前帧设键。
6. 点击“应用并在当前帧设键”。仪表从 FK 100% 移到 IK 100%。
7. 检查左手位置、手肘方向和输出骨架没有跳变；状态显示最大位置误差。
8. 在 Maya Graph Editor 中可以看到 `ikFk`、IK 控制器、Pole、Twist 和三组 Roll 补偿键。
9. 点击“撤销”。界面必须显示“姿态、属性与新增关键帧均已恢复”。

如果预览后手动移动控制器、改变当前帧或修改 `ikFk`，旧计划会因指纹不一致而拒绝应用，需重新预览。

## 3. IK → FK 无跳变匹配

1. 在已构建的肢体上把 `ikFk` 切到 1，并移动 IK 和 Pole 控制器形成姿态。
2. 点击对应手臂或腿部模块。
3. 点击“预览 IK → FK”，确认计划将匹配三个 FK 控制器。
4. 应用后，MayaCraft 按父控制器到子控制器的顺序写入世界矩阵，再把 `ikFk` 设为 0。
5. 输出关节会被重新采样；位置或矩阵误差超限时整笔事务自动回滚。

## 4. 带关键帧补偿的 Space Switch

1. 打开 `demo/scenes/mayacraft_space_switch.ma`，停在第 12 帧。
2. 在动画匹配舱选择“胸腔空间”，点击“预览空间切换”。
3. 预览应显示“第 11 帧保护键 + 第 12 帧补偿世界姿态”。
4. 应用后，第 11 帧保留旧空间和旧局部通道；第 12 帧切换到胸腔并写入补偿后的平移、旋转。
5. 在第 12 帧观察手腕不跳；继续播放后，手腕会跟随胸腔动画。
6. 点击“撤销”，确认空间属性、控制器姿态和新增关键帧都被恢复。

## 5. 失败与恢复

打开 `demo/scenes/mayacraft_match_locked.ma`。左手 IK 控制器的 `translateX` 被锁定。点击
“预览 FK → IK”后应显示红色预检阻断，应用按钮保持禁用，场景和 Undo 队列不发生写入。

打开 `demo/scenes/mayacraft_skeleton_blocked.ma` 并扫描骨架。该层级本身是合法关节链，但不满足黄金双足
模板；界面会列出缺少的胸腔、头部和四肢语义，不允许把未绑定节点堆在原点。

## 6. 目前边界

- 只支持 Maya 2025 和 MayaCraft 黄金双足生成的三段手臂/腿部模块；
- 空间列表目前为全局和胸腔；自定义任意空间管理器仍在后续路线；
- Roll 补偿是 MayaCraft Rig Graph 的内部关键通道，不应在旧 legacy 绑定上直接调用；
- Guide 高级编辑、Face PSD/RBF 和拓扑变化蒙皮迁移不属于 2.3 目标。

## Bendy 形变弧场

1. 打开 `demo/scenes/mayacraft_bendy_sculpt.ma`，停在第 12 帧并点击左臂模块。
2. 点击“打开形变弧场”，选择上段或下段骨段。
3. 拖动两枚橙色切线把手改变入弧/出弧；拖动中央“肌腹”可整体推弯，也可切换自然 C 弧、反向 S 弧和直线。
4. 调整“体积保持”。此时只更新形变带，Maya 控制器和曲线不发生变化。
5. 点击“生成零写入计划”，检查目标弧长、三枚 Bendy 关节和截面比例。
6. 点击“应用并验证”。MayaCraft 移动两枚真实切线控制器，并重采样三枚 motionPath 关节；控制器误差或关节误差超限会自动回滚。
7. 旋转骨段末端，确认三个 Twist 子关节仍沿弧线分配扭转；点击撤销，确认切线、体积和关节恢复。

如果预览后移动骨段、切线控制器、改变体积或当前帧，计划指纹会失效。切线平移或体积属性被锁定、引用或已有输入时，应用按钮保持禁用并显示具体 plug。

## Quaternion Twist 能量塑形

1. 打开 `demo/scenes/mayacraft_twist_sculpt.ma` 并停在第 12 帧。
2. 进入“绑”，点击左臂模块，再点击“进入 Twist 能量塑形舱”。
3. 当前上段会读到约 `+90°` 纯 Twist；三枚发光节点默认显示 `25 / 50 / 75`。
4. 把“分布偏置”拖到 `-0.65`、“缓入曲线”设为 `85%`、“扭转强度”设为 `90%`。
5. 此时只有能量场变化；点击“预览分布”后应看到 `J1 54% · J2 85% · J3 90%` 的零写入计划。
6. 点击“应用并验证”，三枚 Twist 关节会通过 Maya 2025 内置 `quatNodes` 实时更新。
7. 点击撤销，界面必须显示权重和关节姿态已恢复。若任意 slerp 权重被锁定或已有输入，预览会红色阻断。
